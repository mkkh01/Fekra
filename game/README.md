# سِيَر الممالك — نموذج أولي مرئي (v0.1)

نموذج playable في المتصفح: خريطة مقاطعات إجرائية، دولتان، جيوش بأوامر،
معارك بنبضات، اقتصاد بسيط، حفظ/تحميل — بدون أي سيرفر أو قاعدة بيانات.

وثيقة التصميم الكاملة: [`war_world_game_design-1.md`](../war_world_game_design-1.md)

## التشغيل

المتطلبات: Node.js 18+

```bash
cd game
npm install
npm run dev      # ثم افتح http://localhost:5173
```

أوامر أخرى:

```bash
npm run check    # فحص TypeScript
npm run test     # اختبارات Vitest
npm run build    # بناء نسخة الإنتاج
```

## كيف تلعب؟

- انقر **مقاطعة** لعرضها، وانقر **جيشًا أخضر** (جيوشك) لتحديده.
- والجيش محدد: انقر أي مقاطعة لتحريكه إليها / مهاجمتها.
- غيّر **الموقف** (هجومي/دفاعي/متوازن) و**التشكيل** (خط/رتل/منتشر) — كلها مؤثرة فعليًا.
- 🏆 الهدف: احتل **عاصمة دولة الغسق** (النجمة الذهبية في المناطق الحمراء).
- 🗺️ عجلة الفأرة للتقريب، السحب للتحريك، مسافة = إيقاف مؤقت، 1/2/3 = السرعات.
- 💾 الحفظ في المتصفح (localStorage). `?seed=123` في الرابط = عالم مختلف.

## القرارات المثبتة في هذا النموذج

| القرار | القيمة |
|---|---|
| نموذج الخريطة | مقاطعات (Voronoi على شبكة) |
| المعارك | حسم بنبضات + مواقف وتشكيلات (المناورات الدقيقة لاحقًا) |
| الواجهة | خريطة Canvas + لوحات DOM (عربي RTL) |
| الزمن | النبضة = ساعة، اليوم = 24 نبضة، السنة = 360 يومًا |
| الحتمية | RNG ببذرة (mulberry32) + نبضات ثابتة |
| الحفظ | JSON مُصدَر (إصدار 1) في localStorage |
| قاعدة بيانات؟ | لا — لعبة فردية محلية بالكامل |

## تبسيطات مؤقتة (ستُعالج في المراحل التالية)

- دولتان فقط بدل 20، وذكاء اصطناعي بسيط بمعلومات كاملة (لا ضباب حرب بعد).
- لا دبلوماسية ولا تجسس ولا أخبار مولّدة بالقوالب بعد.
- الجيش العابر بين مقاطعتين يُحسب على مقاطعته الأصلية مؤقتًا.
- لا أصوات بعد.
